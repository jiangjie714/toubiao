### 已知问题：安徽 502 抖动（非配置问题）

`ggzy.ah.gov.cn` 的 `newDetailSub` 与 `/jsgc/list` 对本机出口 IP 有约 40%~60% 概率直接返回 HTTP 502，失败固定耗时 ~6.3s（网关超时）；同一时刻换出口（走本地代理）则 100% 200。已排除：连接复用（`Connection: close`/`keepAliveTimeout`/`pipelining:0`）、HTTP/2（站点只支持 1.1）、请求头差异（curl 与 undici 对齐后仍抖动）、GET/POST 差异（均抖动）。

处置：不做代码级绕过，`settings.retries: 7`（共 8 次尝试，指数退避 1s→8s，单条成功率 ≈ 99.9%）。同时把 fetcher 的重试退避从固定 `1000*(attempt+1)` 改为指数 + 抖动，因为站方 502 成簇出现，固定间隔容易整簇失败。
