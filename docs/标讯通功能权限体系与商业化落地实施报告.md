## 一、 执行摘要与商业客群二元分层

招投标信息聚合与大数据服务（对标行业先行者千里马招标网、剑鱼标讯等）在商业化变现模式上具备高度典型的**“二元结构”**：

```
                    ┌─────────────────────────────────────────────────────────┐
                    │               标讯通商业化营收结构金字塔                    │
                    └────────────────────────────┬────────────────────────────┘
                                                 │
                  ▲                              │
                 / \                             │
                /   \     【个人散客】            │ 现金流与用户漏斗补充
               / 散客 \    39元/月 · 99元/月       │ 占总营收 < 20%
              /───────\   工具型即时自费垫付       │ 极速扫码、即付即走、单点突破
             /         \                         │
            /   企业    \  【企业客户】            │ 现金流与利润主力贡献者
           /    客户     \ 6,800元/年 · 16,800元/年 │ 占总营收 > 80%
          /───────────────\生产力系统+组织资产     │ 对公转账、专票抵扣、团队协同
```

1. **企业客户（中小企业老板 / 销售总监）——主力营收支柱（贡献 80% 以上现金流）**：
   - **单价高**：年费 6,800 元（企业标准版）与 16,800 元（企业专业版），客单价高，LTV（生命周期总价值）高。
   - **痛点重**：解决企业投标过程中“信息漏看、资质过期废标、保证金沉淀、销售撞单、方案一票否决”等致命风险。
   - **财务刚性**：资金走企业银行公户报销，**必须走公对公电汇打款、必须签署正规《技术服务采购合同》、必须开具“\*信息技术服务\*软件信息技术服务”6% 增值税专用发票（用于进项税抵扣）**。
2. **个人散客（投标专员 / 销售新人 / 自由中介）——用户规模基座与引流漏斗（贡献 20% 现金流）**：
   - **单价低**：39 元/月（黄金会员）与 99 元/月（铂金会员），价格敏感度高。
   - **场景急**：往往因为当天下午要投递某项目，或者要紧急联系业主/代理机构，急需获取“**特定项目的采购人电话、底价预算或招标文件原件**”。
   - **决策快**：属于个人自费垫付，微信/支付宝 Native 扫码 2 秒内完成付款，付完即用，用完即走，不关心组织架构与企业管理工具。

## 二、 客群深度画像、付费心理与交易链路设计

### 2.1 个人散客 vs 企业客户 深度对比表

| 核心维度 | 个人散客（投标专员 / 销售新人） | 企业客户（中小企业老板 / 销售总监） |
| :--- | :--- | :--- |
| **典型代表角色** | 投标专员、售前技术支持、区域销售新人、自由居间人 | 中小工程施工企业老板、系统集成商销售总监、投标部主管 |
| **定价与周期** | **39 元/月**（黄金版）· **99 元/月**（铂金版）<br>（支持 299 元/年 · 799 元/年） | **6,800 元/年**（企业标准版，3席位）<br>**16,800 元/年**（企业专业版，10席位） |
| **购买决策心理** | **“救急与窥探”心理**：<br>“我手上就缺这个项目的招标专员电话和招标控制价，几十块钱我微信扫一下就能看到，不用求人，也不用走公司流程。” | **“风控与组织增效”心理**：<br>“一年投标几十次，漏一个标丢几百万；资质过期扣分直接废标；几十万保证金退没退不知道；买系统是买团队风控保险。” |
| **心理账户** | 个人零花钱 / 垫付报销账户（<100 元免批） | 企业经营预算 / 销售拓展费 / IT信息化采购支出 |
| **交易支付方式** | **个人微信扫码支付 / 支付宝移动支付** | **银行公对公转账电汇**（对公网银或银行柜台转账） |
| **支付合规约束** | 零合规约束，怎么快怎么来，拒绝繁琐信息填写 | **严禁员工用个人微信向个人码转账几千上万元**（无法做账报销，涉嫌违规套现与资金挪用） |
| **合同与票据** | 无需合同，默认同意线上服务条款；<br>极少需要发票，如需仅开个人电子普票 | **必须具备正规合同（盖鲜章/电子签）**；<br>**必须开具 6% 增值税专用发票（进项税额抵扣 408~1008 元）** |
| **核心使用价值** | 快速查电话、找底价、下附件、读正文 | 团队商机池协同、企微推送、资质预警、保证金跟踪、AI清标 |
| **服务期望** | 线上自助、秒级开通、无人工打扰 | 专属客户经理（CSM）、到账人工加急核销、业务专属答疑 |

### 2.2 交易支付与交付全流程差异

```
【个人散客交易流】：
用户前台检索 ──► 遇到联系人/底价付费墙 ──► 弹窗微信扫码 ──► 微信支付成功 ──► 异步回调 2 秒内激活 ──► 立即查看

【企业客户交易流】：
企业选型试用 ──► 选定企业版并提交订单 ──► 系统生成订单号与专属对公转账识别码
   ├──► 下载带有防伪签章的《技术服务采购合同》PDF ──► 内部发起OA采购付款审批
   └──► 财务网银发起对公转账（附言填写订单号） ──► 上传打款回单 / 银行流水自动匹配
        └──► 平台财务确认到账 ──► 激活主管理员账号与多席位 ──► 自动开具6%增值税专票并顺丰寄送/电子送达
```

## 三、 系统全景功能域解构（八大业务域）

经过对标讯通全站功能、页面路由（`src/app/(site)/`）及底层数据模型的全量盘点，整体系统划分为八大功能域：

1. **全网标讯检索域**（`/list`, `/tender/[id]`, `/regions`, `/industries`）：跨 31 省市全品类招投标、政府采购、更正变更、中标公示检索。
2. **深度商业情报域**（`/projects`, `/purchasers`, `/suppliers`, `/history`, `/intentions`）：联系人信息、控制价底价、项目全生命周期主数据、业主画像、中标底价历史库、政府采购意向提前截流。
3. **AI 智能赋能域**（`/audit`, `/proposals`, 标讯详情 AI 模块）：AI 标讯速读提炼、评分规则拆解、投标文件 AI 清标质质检（一票否决项扫描）、标书工程智能装配。
4. **商机监控与推送域**（`/watches`, `/brief`, `/calendar`, `/webhooks`）：关键词雷达盯标、每日早报订阅、截标备忘日历、企业微信/钉钉/飞书群机器人实时告警。
5. **销售协同与 CRM 域**（`/pipeline`, `/team`, `/tracker`）：企业多席位分配、商机流水线跟踪看板、团队共享项目池、内部协作便签与评语。
6. **企业资产与风险风控域**（`/qualifications`, `/deposits`, `/cases`, `/reviews`, `/competitors`）：企业资质证照库（临期废标预警）、投标保证金全流程台账、经典中标案例库、失标复盘归因库、宿敌竞对雷达监控。
7. **数据资产导出与开放集成域**（`/exports`, `/developer`）：Excel 高级标讯数据批量导出、导出防爬合规审计日志、Open API Key 开发者网关接口。
8. **财税合规与运营结算域**（`/pricing`, `/pay/[orderNo]`, `/contract/[orderNo]`, `/invoices`）：多渠道在线收银台、对公转账流水核销、电子合同即时生成、金税四期增值税专票与开票资料库。

## 五、 功能重叠与差异化的底层商业逻辑剖析

### 5.1 为什么这些功能必须「完全重叠」？（公共核心底座）
1. **真实有效的联系人与底价必须向个人（铂金版 99元）开放**：
   - 个人散客付 99 元绝不是为了“看看页面排版”，其核心痛点就是“拿电话、探底价”。
   - 如果 99 元看不到电话，散客绝对不会买；而散客更不可能因为想看一个电话就自掏腰包花 6,800 元买企业版。
   - **重叠的本质是：同一份数据资产，通过“单兵使用”和“组织协同”两种完全不同的形态进行双轨变现**。
2. **全网覆盖度与更新时效性必须完全一致**：
   - 数据库必须一致，不能对个人散客故意推迟 2 天展示。标讯讲究时效，信息推迟会导致平台口碑崩塌。数据全面与时效是全平台的信誉底座。

### 5.2 为什么这些功能必须「筑起坚固壁垒」？（企业 6,800~16,800 元的溢价支柱）
企业客户之所以愿意掏出个人版年费 10~20 倍的预算，买的根本不是“多查几个手机号”，而是以下**四维组织壁垒**：

1. **协同壁垒（防撞单与资产留痕）**：
   - 个人版是“单兵过客”，员工离职，关注的项目直接丢失；
   - 企业版是“企业资产”，销售总监在公海池派单，销售 A 跟进后锁定客户，销售 B 自动避让；全过程跟进记录、洽谈纪要沉淀在公司系统内。
2. **风控壁垒（防几十万巨额损失与废标）**：
   - 一次大标因为“某资质证书过期 1 天”导致资格审查一票否决，损失不可估量；
   - 一笔投标保证金 20 万元因为财务忘记开标时间，沉淀半年未退导致流动资金紧张；
   - 企业版的**资质到期红色预警**与**保证金催退日历**，属于企业经营的“刚性避险工具”。
3. **触达壁垒（企微/钉钉群组织化集成）**：
   - 散客看邮件，企业靠协同软件。将符合企业经营品类的标讯第一秒推送到“华东销售战区企微群”，全员自动启动响应，是企业级响应速度的保障。
4. **财税与采购法壁垒（合规通行证）**：
   - 中小企业财务制度严格：没有盖章采购合同不能立项；没有银行公对公转账流水不能出账；没有“\*信息技术服务\*软件信息技术服务”的 6% 增值税专用发票无法通过税务稽查与抵扣进项。这一套财税闭环是个人私下扫码支付绝对无法逾越的护城河。

## 六、 付费墙机制、防套利策略与转化漏斗

### 6.1 个人散客的“秒级促单”付费墙设计
个人散客具有极高的冲动消费和即时满足特征，链路必须做到**“零跳转、零多余输入、2秒解密”**：

1. **视觉呈现（信息遮罩）**：
   - 访问标讯详情页时，采购人及代理机构联系方式显示为局部模糊，并标注醒目提示：
     > `采购联系人：张**  联系电话：138****9281`  
     > `[ 查看完整联系人及电话 ]`
2. **一键唤起即时收银卡片**：
   - 点击后在当前页面弹出轻量浮层：
     - **极速方案**：开通【铂金会员】99元/月（即刻查看全网所有项目联系人与底价）
     - **实惠备选**：开通【黄金会员】39元/月（仅看底价与全文，不含电话）
   - 弹窗内直接渲染微信支付 Native 动态收款二维码。
3. **异步秒级解锁**：
   - 手机微信扫码支付成功后，前端 WebSocket / 轮询在 1.5 秒内收到回调，弹窗自动关闭，被遮蔽的手机号直接转为明文（如 `张建国 13812345678`），并支持一键复制。

### 6.2 企业客户的“升舱与线索转化”漏斗
平台在积累个人散客的同时，散客数据也是企业大客户的天然线索池：

```
个人用户注册/使用 ──► 系统算法识别企业属性 ──► 触发升舱钩子 ──► 引导对公转账与试用 ──► 商务跟进企业大单
```

1. **企业属性识别探针**：
   - **企业域名邮箱识别**：凡使用公司企业邮箱（如 `@xxxx.com` 而非 `@qq.com`、`@163.com`）注册的用户；
   - **同主体并发访问识别**：检测到同一个公司主体名称、或同一个局域网 IP 段内有 2 个以上个人账号频繁查询同行业标讯；
   - **高频导出触发**：个人账号连续两天达到 20 条导出上限并尝试继续导出时。
2. **定向升舱权益引导**：
   - 系统在页面顶部浮现尊享提示：
     > “检测到您正在为 **【某某建设工程有限公司】** 筛选商机，个人版无法多人协同。立即申请升级【企业标准版】，支持 3 席位协同、开具 6% 专票与对公打款！”
   - 提供 **“免费申请 7 天企业协同试用”** 按钮，收集企业全称与职务信息，自动分发给商务团队进行企业级公关。

### 6.3 严格防套利与风控体系（严防“个人号企业用”）
1. **设备与单端登录互踢机制**：
   - 个人黄金/铂金会员严格限制 **1 个账号同时仅允许 1 台设备在线**。在另一台电脑登录时，前一设备强制下线并提示“账号已在其他终端登录”。从根源上阻止一个 99 元账号给整个销售团队 10 个人轮流使用的行为。
2. **按日配额频次刚性熔断**：
   - 个人黄金版 20 次/日，铂金版 60 次/日，由 Redis / PostgreSQL `QuotaLedger` 刚性锁定，超限即弹出提示“今日个人查询额度已满，如需团队不限量检索请升级企业版”。
3. **数据批量防爬脱敏**：
   - 个人版导出限制为 20 条/日，且导出文件中**自动剔除联系人电话字段**，避免爬虫黑产通过 99 元购买个人月卡后疯狂批量扒取全网电话数据倒卖。

## 七、 对公转账、电子合同与金税四期专票闭环体系

### 7.1 银行公对公转账流程设计
1. **订单生成与唯一打款识别码**：
   - 用户在定价页勾选“企业标准版 / 专业版”，选择“银行对公转账”结算方式；
   - 系统生成唯一对公订单号（例如 `GS-202609-88192`）；
   - 页面与确认邮件向用户明确展示我司银行结算户信息：
     - **账户名称**：标讯通软件技术（北京）有限公司（示例）
     - **开户银行**：招商银行股份有限公司北京分行大运村支行
     - **银行账号**：1109 0000 0000 000
     - **汇款附言/备注（强制）**：`GS-202609-88192`（系统唯一识别码）
2. **回单上传与快速核销**：
   - 客户财务在网银打款后，可在订单中心上传“银行电子回单”图片/PDF；
   - 平台后台财务人员每日对账，根据汇款备注中的订单号，在管理后台（`src/app/admin/orders`）一键点击“确认到账”，订单状态即刻转为 `PAID`；
   - 系统自动激活企业主账号，并解锁对应席位邀请链接。

### 7.2 电子采购服务合同自动化与防伪
中小企业财务付款前，必须见合同。平台支持全自助合同流：
1. **在线预览与下载盖章合同**：
   - 订单生成后，客户点击“下载采购合同”；
   - 系统依据订单信息、金额（6,800.00元）、企业抬头，自动组装生成 PDF 版《标讯通企业版大数据软件信息技术服务采购合同》；
   - 合同自带我司加盖的公章图片、防伪合同骑缝编号、双方权利义务及 6% 开票约定；
2. **双向签署支持**：
   - 支持客户直接打印盖章后拍照回传，或通过集成契约锁/e签宝进行电子公章在线验签。

### 7.3 金税四期 6% 增值税专用发票开具规范
1. **税收编码与开票品目**：
   - **税目类别**：信息技术服务
   - **标准品目名称**：`*信息技术服务*软件信息技术服务`
   - **法定税率**：**6%**（一般纳税人法定税率，完全合规）
   - **税额抵扣测算**：
     - 6,800 元企业标准版：不含税金额 6,415.09 元，**税额 384.91 元**；
     - 16,800 元企业专业版：不含税金额 15,849.06 元，**税额 950.94 元**；
     - 客户财务可凭此专用发票抵扣等额进项税，直接降低企业真实采购成本。
2. **企业开票资质档案库（`InvoiceProfile`）**：
   - 企业在后台一次性录入并保存：
     - 企业全称（发票抬头）
     - 纳税人识别号（统一社会信用代码）
     - 注册地址及联系电话
     - 开户银行及对公银行账号
     - 专票接收邮箱 / 纸质发票顺丰寄送地址及收件人
3. **开票流程**：
   - 订单标记 `PAID` 后，后台发票列表（`src/app/admin/invoices`）自动生成待开票任务；
   - 财务开具数电专票（XML/PDF）上传系统，系统自动向客户邮箱发送电子专票，并在前台订单中心提供即时下载。

   - 对于免费和黄金会员，在 Server Component / Server Action 获取 `OrgContact` 联系方式时，直接在服务端将 `phone` 字段重置为 `null` 或替换为脱敏占位符（如 `138****0000`）。严禁将未脱敏数据传到浏览器前端后用 CSS `filter: blur()` 进行假遮罩，防止技术用户通过浏览器 F12 网络请求直接窃取联系人。
2. **多租户数据隔离**：
   - 企业版相关功能（`TenderFollow`, `BidDeposit`, `CompanyQualification`, `CompanyCase`, `TeamMember`）均携带 `teamId` 外键关联。
   - 所有企业级写操作与查询操作，必须严格校验当前登录用户的 `teamId`，确保租户数据物理级隔离，杜绝跨企业越权访问。
3. **配额扣减与并发防刷**：
   - 严格复用系统的 `QuotaLedger` 表机制，通过每日原子自增（`increment: 1`）并带版本检查，防止多标签页并发请求绕过每日搜索或导出上限。
