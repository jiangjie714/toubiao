# 标讯通 生产部署配置清单

> 目标：把开发态（localhost / 裸 IP / 无 SMTP / 本地聚合支付）收敛为**可对外收款的生产态**。
> 配置唯一来源为项目根目录 `.env`；`docker compose` 启动时会强制校验必填项（缺失即 fail-fast）。

---

## 0. 配置源与快速路径

```bash
cp .env.example .env          # 逐项填写下方【必填】
docker compose config         # 预览校验（缺必填项会立即报错）
docker compose up -d --build  # 构建并启动
```

- `.env` 已被 `.gitignore` 与 `.dockerignore` 双重排除：**不会进仓库、不会打进镜像**。
- 容器内所有业务变量（SMTP/支付/企业微信/AI）统一通过 compose `env_file` 注入，不再逐项遗漏。

### 必填项（缺失即拒绝启动）

| 变量 | 说明 |
| --- | --- |
| `APP_URL` | 生产 https 域名，如 `https://www.your-domain.com` |
| `AUTH_SECRET` | 会话签名密钥，`openssl rand -hex 32` |
| `POSTGRES_PASSWORD` | 数据库密码，需与 `DATABASE_URL` 中密码一致 |

生产额外建议：`NEXT_PUBLIC_APP_URL`、`SMTP_*`、`COMPANY_*`、支付商户 `*_NOTIFY_URL`。

---

## 1. 域名 + HTTPS（最高优先级）

现状问题：`APP_URL` 为 `http://<公网IP>:3000`，会话 Cookie 无 `Secure`，用户凭据易被窃听；IP 直连无法完成备案与支付回调校验。

- [ ] 购买并解析域名（A 记录 → 服务器公网 IP；如需 CDN 用 CNAME）。
- [ ] 前置反向代理终止 TLS，应用端口**只绑定回环**（已在 compose 设为 `127.0.0.1:3000`）。
- [ ] `APP_URL` 改为 `https://域名`（此时 `src/lib/auth.ts` 会自动给会话 Cookie 加 `Secure`）。

Caddy 最小示例（自动申请并续期 Let's Encrypt 证书）：

```caddyfile
www.your-domain.com {
    encode gzip
    reverse_proxy 127.0.0.1:3000
}
```

Nginx 需自行配置证书与 `proxy_set_header X-Forwarded-Proto https;`。

- [ ] **ICP 备案**（域名指向境内服务器时必须）。备案完成前不要对外宣传收费。
- [ ] **公安联网备案**（ICP 备案通过后办理）。

## 3. 邮件通知（SMTP）

现状问题：`SMTP_HOST` 为空 → `src/lib/mailer.ts` 只打印日志，**验证码/订阅推送不发信**。

- [ ] 选择服务商（阿里云邮件推送 / 腾讯云 SES / 自建 Postfix）。
- [ ] 配置发信域名 SPF / DKIM / DMARC，避免进垃圾箱。
- [ ] 填写 `SMTP_HOST/PORT/SECURE/USER/PASSWORD/FROM`。
- [ ] `SMTP_FROM` 使用已认证域名邮箱（如 `no-reply@your-domain.com`）。

## 4. 支付通道（回调域名是前置条件）

现状问题：生产默认走 `JEEPAY_PAY_URL=http://127.0.0.1:9216` 本地聚合网关，公网不可达。

统一要求：所有 `*_NOTIFY_URL` 必须是**公网可访问的 https** 地址。

- [ ] 部署/托管 Jeepay 网关（或改用直连微信/支付宝），填写 `JEEPAY_PAY_URL/MCH_NO/APP_ID/API_KEY`。
- [ ] `JEEPAY_NOTIFY_URL = https://域名/api/payment/jeepay/notify`
- [ ] `JEEPAY_RETURN_URL  = https://域名/pricing`
- [ ] 直连模式同理配置 `WECHAT_PAY_*`（含 API v3 密钥与平台证书）、`ALIPAY_*`。
- [ ] 以沙箱/小额真实订单验证：下单 → 支付 → 回调验签 → 开通权益 → 主动查单兜底。

## 6. 数据与运维

- [ ] 数据库结构变更**默认不做破坏性同步**：生产用 `RUN_DB_PUSH=false`；
      如需同步，显式 `RUN_DB_PUSH=true`，且仅当确认可丢数据时才加 `RUN_DB_PUSH_ACCEPT_DATA_LOSS=true`。
- [ ] 首次初始化数据（省市区划 / admin 账号 / 数据源）**只跑一次**：`RUN_DB_SEED=true`。
- [ ] 备份：`postgres-data` 卷定期 `pg_dump`，异地留存。
- [ ] 首次登录后立即修改 `admin` 密码。
